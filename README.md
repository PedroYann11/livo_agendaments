# Livo Agenda

Plataforma de agendamento online e gestão para negócios de serviço
(barbearias, salões, estética, clínicas, profissionais autônomos).

- **Cliente final:** marca o horário em menos de 1 minuto, sem criar conta, e
  recebe um link para reagendar ou cancelar.
- **Dono:** abre o painel e vê a agenda do dia; gerencia serviços, equipe,
  clientes, lembretes por WhatsApp, financeiro e comissões.

Construída sobre a fundação da [Livo](https://github.com/PedroYann11/livo)
(multi-tenant, RLS, design system do painel), **copiada** para cá — o
repositório `livo` não é alterado.
